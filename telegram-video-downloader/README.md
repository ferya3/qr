# Telegram Video Downloader (اکستنشن کروم)

دانلود ویدیو از گروه‌ها و کانال‌های تلگرام — از جمله گروه‌های **خصوصی** که عضوشان هستید — از داخل [Telegram Web](https://web.telegram.org).
با هر دو نسخهٔ Web K (`/k`) و Web A (`/a`) کار می‌کند.

## نصب

1. این پوشه (`telegram-video-downloader`) را دانلود کنید.
2. در کروم به `chrome://extensions` بروید.
3. **Developer mode** را (بالا سمت راست) روشن کنید.
4. روی **Load unpacked** بزنید و همین پوشه را انتخاب کنید.
5. صفحهٔ Telegram Web را اگر باز است یک‌بار رفرش کنید.

## استفاده

1. ویدیو را در Telegram Web باز کنید (کلیک روی ویدیو).
2. ماوس را روی ویدیو ببرید؛ دکمهٔ **دانلود** گوشهٔ بالای ویدیو ظاهر می‌شود.
3. یا کلید میانبر <kbd>Alt</kbd>+<kbd>D</kbd> را بزنید تا بزرگ‌ترین ویدیوی روی صفحه دانلود شود.
4. پیشرفت دانلود در پایین صفحه نمایش داده می‌شود و قابل لغو است.

## نحوهٔ کار

Telegram Web ویدیوها را از طریق Service Worker خودش به صورت تکه‌تکه (HTTP Range) پخش می‌کند.
اسکریپت اکستنشن داخل خود صفحه اجرا می‌شود و همان آدرس پخش ویدیو را تکه به تکه دریافت کرده،
تکه‌ها را به هم می‌چسباند و به صورت یک فایل کامل ذخیره می‌کند. هیچ داده‌ای به سرور دیگری ارسال نمی‌شود
و اکستنشن به هیچ مجوز خاصی نیاز ندارد.

## نکات

- فقط ویدیوهایی قابل دانلود هستند که حساب شما به آن‌ها دسترسی دارد.
- برای ویدیوهایی که در چت فقط تصویر پیش‌نمایش دارند، ابتدا روی آن‌ها کلیک کنید تا پلیر باز شود.
- ویدیوهای خیلی حجیم در حافظهٔ مرورگر جمع می‌شوند؛ برای فایل‌های چند گیگابایتی رم کافی لازم است.
- لطفاً به حقوق صاحبان محتوا احترام بگذارید.
