# YouTube Downloader (اکستنشن کروم + yt-dlp)

یک دکمهٔ قرمز **دانلود** کنار دکمهٔ لایک یوتیوب اضافه می‌کند. با آن می‌توانید ویدیو را با کیفیت دلخواه
(4K تا 360p) یا فقط صدای آن را به صورت MP3 دانلود کنید. فایل‌ها در پوشهٔ **Downloads** ذخیره می‌شوند.

دانلود را برنامهٔ رایگان و متن‌باز [yt-dlp](https://github.com/yt-dlp/yt-dlp) روی کامپیوتر خودتان انجام می‌دهد.
به همین دلیل با تغییرات یوتیوب از کار نمی‌افتد و فقط کافی است گاهی آن را به‌روز کنید.

```
extension/   ← اکستنشن کروم
host/        ← برنامهٔ کمکی که yt-dlp را اجرا می‌کند
```

---

## نصب روی ویندوز

1. **Python** را نصب کنید: از [python.org](https://www.python.org/downloads/) دانلود کنید و هنگام نصب تیک
   **Add python.exe to PATH** را بزنید.
2. **ffmpeg** و **deno** را نصب کنید. PowerShell یا Command Prompt را باز کنید و بزنید:
   ```
   winget install Gyan.FFmpeg
   winget install DenoLand.Deno
   ```
3. پوشهٔ `youtube-downloader` را در جای ثابتی بگذارید (مثلاً `C:\Tools\youtube-downloader`).
   بعد از نصب آن را جابه‌جا نکنید.
4. داخل پوشهٔ `host` روی فایل **`install.bat`** دو بار کلیک کنید.
5. در کروم به `chrome://extensions` بروید، **Developer mode** را روشن کنید، روی **Load unpacked** بزنید
   و پوشهٔ **`extension`** را انتخاب کنید.
6. کروم را کامل ببندید و دوباره باز کنید.

## نصب روی مک

1. اگر [Homebrew](https://brew.sh) ندارید، نصبش کنید. بعد در Terminal بزنید:
   ```
   brew install python ffmpeg deno
   ```
2. پوشهٔ `youtube-downloader` را در جای ثابتی بگذارید (مثلاً در پوشهٔ Documents).
3. در Terminal بزنید (مسیر را با مسیر پوشهٔ خودتان عوض کنید):
   ```
   sh ~/Documents/youtube-downloader/host/install.sh
   ```
4. مثل قدم ۵ و ۶ ویندوز، پوشهٔ `extension` را در کروم Load کنید و کروم را ری‌استارت کنید.

> لینوکس هم مثل مک است: `ffmpeg` را با مدیر بستهٔ توزیع نصب کنید و `install.sh` را اجرا کنید.

## بررسی نصب

روی آیکون اکستنشن در نوار کروم بزنید. باید «برنامهٔ کمکی: متصل ✓» و نسخهٔ yt-dlp را ببینید.
اگر ffmpeg یا deno نصب نباشند، همان‌جا هشدار داده می‌شود.

## استفاده

1. ویدیو را در یوتیوب باز کنید.
2. روی **دانلود** (کنار لایک) بزنید و کیفیت را انتخاب کنید.
   در Shorts دکمه گوشهٔ پایین صفحه ظاهر می‌شود.
3. پیشرفت دانلود پایین سمت چپ صفحه نمایش داده می‌شود و قابل لغو است.
   بعد از اتمام، با کلیک روی اسم فایل، پوشهٔ آن باز می‌شود.

## به‌روزرسانی

یوتیوب هر چند وقت یک بار چیزهایی را عوض می‌کند. اگر دانلود با خطا مواجه شد، فقط
`install.bat` (ویندوز) یا `install.sh` (مک) را **دوباره اجرا کنید** تا yt-dlp به آخرین نسخه به‌روز شود.

## حذف

`python host/uninstall.py` را اجرا کنید و اکستنشن را از `chrome://extensions` حذف کنید.

## چرا ffmpeg و deno؟

- **ffmpeg:** یوتیوب کیفیت‌های بالاتر از 360p را به صورت تصویر و صدای جدا می‌فرستد.
  ffmpeg این دو را به یک فایل MP4 تبدیل می‌کند. تبدیل به MP3 هم با ffmpeg انجام می‌شود.
- **deno:** yt-dlp برای باز کردن رمز لینک‌های یوتیوب به آن نیاز دارد. بدون آن ممکن است همهٔ کیفیت‌ها پیدا نشوند.
