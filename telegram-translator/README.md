# Telegram Translator (اکستنشن کروم)

ترجمهٔ خودکار پیام‌های [Telegram Web](https://web.telegram.org) — مثلاً روسی، انگلیسی یا عربی به فارسی.
ترجمه زیر متن اصلی هر پیام نمایش داده می‌شود. با هر دو نسخهٔ Web K (`/k`) و Web A (`/a`) کار می‌کند.

## امکانات

- **ترجمهٔ خودکار پیام‌ها** به زبان دلخواه (پیش‌فرض: فارسی). پیام‌هایی که از قبل به همان زبان هستند ترجمه نمی‌شوند.
- **ترجمهٔ پیامی که می‌نویسید** به زبان طرف مقابل (پیش‌فرض: روسی): متن را فارسی بنویسید،
  روی دکمهٔ آبی بالای کادر پیام بزنید یا <kbd>Alt</kbd>+<kbd>T</kbd> را بزنید. متن با ترجمه جایگزین می‌شود
  و قبل از ارسال می‌توانید آن را ببینید (با <kbd>Ctrl</kbd>+<kbd>Z</kbd> به متن اصلی برمی‌گردد).
- <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd>: روشن/خاموش کردن سریع ترجمهٔ خودکار.
- دو موتور ترجمهٔ رایگان (Google و Microsoft)؛ اگر یکی در دسترس نبود، خودکار از دیگری استفاده می‌شود.
- فقط پیام‌هایی که روی صفحه دیده می‌شوند ترجمه می‌شوند و ترجمه‌ها کش می‌شوند.

## نصب

1. پوشهٔ `telegram-translator` را دانلود کنید.
2. در کروم به `chrome://extensions` بروید و **Developer mode** را روشن کنید.
3. روی **Load unpacked** بزنید و همین پوشه را انتخاب کنید.
4. صفحهٔ Telegram Web را رفرش کنید.

تنظیمات (زبان‌ها و موتور ترجمه) با کلیک روی آیکون اکستنشن در نوار کروم.

## حریم خصوصی

متن پیام‌ها برای ترجمه به سرویس Google Translate یا Microsoft Translator فرستاده می‌شود.
برای گفتگوهای خیلی خصوصی می‌توانید ترجمه را با <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd> خاموش کنید.
