# YouTube Live Translator (اکستنشن کروم)

زیرنویس **فارسی همزمان** برای ویدیوهای یوتیوب. اکستنشن زیرنویس ویدیو (دستی یا خودکارِ یوتیوب) را می‌گیرد،
آن را به جمله‌های کامل تبدیل و ترجمه می‌کند و همگام با ویدیو روی پلیر نشان می‌دهد.
در صورت تمایل، ترجمه را با صدا هم می‌خواند (دوبلهٔ ساده).

## امکانات

- زیرنویس ترجمه‌شده روی پلیر (در حالت تمام‌صفحه هم کار می‌کند).
- ترجمهٔ جمله‌به‌جمله به جای کلمه‌به‌کلمه، تا ترجمه روان‌تر باشد.
- ترجمه از همان جایی که ویدیو را تماشا می‌کنید شروع می‌شود، پس زیرنویس تقریباً فوراً ظاهر می‌شود.
- نمایش متن اصلی (زرد) زیر ترجمه، که قابل خاموش شدن است.
- امکان مخفی کردن زیرنویس خود یوتیوب.
- **خواندن صوتی ترجمه:** در زمان صحبت، صدای ویدیو کم می‌شود و ترجمه خوانده می‌شود.
- انتخاب زبان مقصد (پیش‌فرض فارسی)، اندازهٔ متن و سرعت صدا.
- دو موتور ترجمهٔ رایگان (Google و Microsoft) که اگر یکی کار نکند، خودکار از دیگری استفاده می‌شود.
- <kbd>Alt</kbd>+<kbd>Y</kbd>: روشن/خاموش کردن سریع.

## نصب

1. پوشهٔ `youtube-translator` را دانلود کنید.
2. در کروم به `chrome://extensions` بروید و **Developer mode** را روشن کنید.
3. روی **Load unpacked** بزنید و همین پوشه را انتخاب کنید.
4. صفحهٔ یوتیوب را رفرش کنید و یک ویدیو باز کنید.

## خواندن صوتی (اختیاری)

برای این کار باید صدای زبان فارسی روی سیستم نصب باشد:
**ویندوز:** Settings ← Time & Language ← Speech ← Add voices ← Persian.
سپس کروم را ری‌استارت کنید و گزینهٔ «خواندن صوتی ترجمه» را در تنظیمات اکستنشن روشن کنید.
اگر صدا نصب نباشد، تنظیمات اکستنشن هشدار می‌دهد.

## محدودیت‌ها

- فقط برای ویدیوهایی کار می‌کند که زیرنویس (دستی یا خودکار) دارند؛ بیشتر ویدیوهای انگلیسی زیرنویس خودکار دارند.
- اکستنشن صدای ویدیو را مستقیم نمی‌شنود؛ ترجمه بر اساس زیرنویس است.
- پخش زندهٔ (Live) یوتیوب معمولاً زیرنویس قابل دریافت ندارد.
